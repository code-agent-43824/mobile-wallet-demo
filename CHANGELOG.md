## [1.60.0] - 2026-10-30

### Added

- Сборки для компьютеров: Windows x64 и arm64, Linux x64 и arm64, macOS (universal). Ограничения те же, что
  у версии для Windows: биометрия имитируется, нет WalletConnect и карт, QR читается из файла.
- Конвейер выпуска на GitHub: каждая цель собирается на раннере своей ОС и архитектуры. Затем на таком же
  раннере запускается релизная сборка и проходит сценарий в приложении: создание кошелька до главного
  экрана. Релиз публикует все сборки только после всех проверок, а в заметки добавляется таблица проверок.
  Android armeabi-v7a, Android arm64 (на раннерах GitHub нет KVM для эмулятора) и iOS-устройство выходят
  с пометкой «не проверено».

### Fixed

- WalletConnect: поддержан `eth_signTypedData` без суффикса. Раньше dApp, которому он обязателен, нельзя
  было подключить.
- WalletConnect: переключение сети работает по-настоящему. Кошелёк добавляет сеть в сессию, сообщает dApp
  событием `chainChanged` и показывает, на какую сеть переключено. Ошибки уходят с кодами EIP-1193/EIP-3326,
  а не с общим «отказом».
- WalletConnect: кошелёк не ждёт бесконечно dApp с «протухшей» страницей. Через 30 секунд он просит
  обновить страницу dApp и отсканировать новый QR-код.
- Удаление отсутствующего ключа из хранилища больше не падает на macOS. Раньше из-за этого ломался отказ
  от биометрии.
- Сборка Windows для Visual Studio 18: `local_auth_windows` снова компилируется.

## [1.59.1] - 2026-10-29

### Added

- Биометрией теперь можно управлять из «Настроек»: строка «Биометрия» заменена тумблером.
  Включение повторно запрашивает PIN кошелька (ключ разворачивается один раз и сохраняется
  под биометрией), выключение удаляет сохранённый секрет. Для карточки строка осталась
  информационной — карточная биометрия включается отдельно.

### Fixed

- Кнопка «Разблокировать биометрией» на экране блокировки перенесена выше — видна
  без прокрутки (раньше уходила под нижний край экрана).

## [1.59.0] - 2026-10-28

### Changed

- Биометрия переведена на `local_auth` 3.0.2: на iOS плагин работает с жизненным циклом UIScene (v1.58),
  на Android он уже на встроенном Kotlin.
- Плагин больше не показывает свои системные окна ошибок, поэтому приложение называет причину само:
  отмена и «ввести PIN» — это отмена, нет датчика или отпечатков — «Биометрия недоступна на этом
  устройстве.», после нескольких неудачных попыток — «Биометрия заблокирована после нескольких неудачных
  попыток. Используйте PIN.»

## [1.58.0] - 2026-10-25

### Fixed

- iOS: в `Info.plist` вернулась конфигурация сцены (`UISceneConfigurations`). Без неё приложение, собранное
  с SDK Xcode 27, падало при запуске.
- Android: на устройствах, где приложение работает не как arm64 (эмуляторы x86_64, 32-битные телефоны),
  оно больше не падает при запуске, а работает без карт: библиотеки карты есть только под arm64-v8a.
  Вместо действий с картой показывается «Аппаратные карты на этом устройстве пока не поддерживаются.»
  Это временно — до библиотек под остальные ABI.
- Проверка 16 KB-выравнивания (`scripts/check_apk_alignment.py`) больше не считает ошибкой 32-битные
  библиотеки: 16 KB-страницы бывают только на 64-битных устройствах.

## [1.57.0] - 2026-10-24

### Added

- Экран «Новая карта»: подключить готовую карту, создать ключ на пустой или записать seed-фразу — в одном
  месте; активный кошелёк не меняется, пока карта не подключена.
- Защита при открытии (по желанию, в «Настройках»): экран блокировки при запуске и после минуты в фоне.
  Телефонный кошелёк открывается PIN или биометрией, карта — PIN и касанием, без подписи.

### Changed

- Каждая подпись и операция с картой проходит в одной шторке: PIN → подпись или касание карты → результат.
  Перевод: форма → проверка → PIN → подпись → результат (ожидание → подтверждение); технические данные —
  в «Подробностях».
- Ошибки доменных слоёв стали кодами и переводятся в интерфейсе: английская версия больше не показывает
  русских сообщений; ошибки карты не называют производителя. Ответы dApp об ошибках — на английском.
- Экран блокировки использует ту же цифровую клавиатуру, что и подписи.

## [1.56.0] - 2026-10-24

### Added

- Влиты v1.54.0+65 и v1.55.0+66: полная RU/EN-локализация с переключателем языка, онбординг
  «Кошелёк за минуту», несколько зарегистрированных карт Рутокен (выбор, «Забыть карту»,
  «Подключить ещё карту», серийный номер карты).
- GitHub Release: по тегу `v*` или ручным запуском CI на `main` с флагом `release` после
  сборки всех платформ публикуется APK с заметками из этого файла (аналог релизного job в GitLab).

### Changed

- Flutter больше не закреплён: CI и `.fvmrc` берут последний стабильный релиз (на момент
  выпуска — 3.47.8); `pubspec.lock` пересобран под него.
- Android: модуль приложения переведён на форму встроенного Kotlin (без `kotlin-android`),
  флаги AGP 9 совпадают с шаблоном `flutter create`; `package_info_plus` поднят до 10.x
  через override, так что Kotlin Gradle Plugin сам применяет только `walletconnect_pay`.
- Убран устаревший override `flutter_secure_storage`: `reown_core` 1.5 принимает 10.x.

### Fixed

- Потеря карты во время операции определяется по присутствию токена, а не по тексту ошибки
  вендора (ждёт физической перепроверки).
- Сборка Android APK на AGP 9.1: `android.newDsl=false` для legacy Kotlin Gradle Plugin.

## [1.0.0] - 2026-10-03

### Added

- Проект перенесён из GitHub (code-agent-43824/mobile-wallet-demo) в группу
  `prototypes` внутреннего GitLab и приведён к стандартам coding-rules.
- Flutter single-account EVM-кошелёк: phone vault (PIN/biometric), read-only

  Rutoken NFC read-only профиль.
- CI/CD: GitLab пайплайн (анализ/тесты на linux-x64 → сборка Android APK на
  android-раннере → публикация в Package Registry + GitLab Release по тегу).
- GitLab Pages: копия документации (README + docs/).
