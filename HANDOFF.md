# Передача работы

`coding-agent` запускает проверку Xcode 27 на GitHub Actions runner `xcode-27`. Следующий шаг —
добавить ручной workflow, выполнить `scripts/smoke/xcode27_simulator.sh`, прочитать лог и записать
результат в матрицу и статус. Локальный Linux smoke прошёл, остальные новые целевые запуски
ещё не проверены.

- WalletConnect: другой агент разбирает уже запущенные тесты и дорабатывает найденное. Не
  перезаписывать его результат; следующий шаг после его отчёта — обновить матрицу, `docs/STATUS.md`
  и `docs/PLAN.md` по фактам.
- iOS-симулятор: `coding-agent` выполняет ручной прогон на раннере `xcode-27`; после результата
  записать версию Xcode, лог и исход в `docs/device-test-matrix.md`, затем обновить статус.
- Выпускной smoke: при следующем запуске прочитать логи двух фаз на iOS, macOS, Windows и Linux;
  до этого не считать их проверенными на новых сценариях.
- Проверки на реальном телефоне с картами и без них владелец пока отложил. Они остаются в
  матрице и не должны закрываться по зелёному CI.

Полный текущий план — в `docs/PLAN.md`; дорожная карта — в `docs/ROADMAP.md`.
