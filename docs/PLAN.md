### Подпись EIP-712: общее превью (начато 2026-11-03 по решению владельца)

- [x] **`wallet_getCapabilities` без `atomic`.** По EIP-5792 `atomic: unsupported` значит «пакеты
  принимаю и выполняю последовательно», а `wallet_sendCalls` кошелёк не принимает. Без `atomic`
  ответ значит «пакетов нет», и dApp сразу шлёт вызовы по одному через `eth_sendTransaction`.
- [x] **Общее превью EIP-712 для WalletConnect.** Сейчас видно только «тип @ домен». Показать домен
  (приложение, версия, сеть, контракт), тип и все поля сообщения. Если это разрешение тратить
  токены (есть `spender`), — заметное предупреждение: кому, сколько (максимум типа — «без
  ограничения»), до какого срока. `chainId` домена, отличный от сети запроса, блокирует подпись:
  такую подпись можно использовать в другой сети.
- [x] **EIP-712 через AirGap** с тем же превью; сеть домена должна быть Mainnet или Sepolia.
- [ ] **Владелец — живой прогон:** `eth_signTypedData_v4` через WalletConnect (Permit на Sepolia) и
  через AirGap из MetaMask.

### Ускорение CI (2026-11-03, решение владельца)

- [x] **Один кэш пакетов Dart на x64-раннерах.** `subosito/flutter-action` с `cache: true` уже
  восстанавливает pub-кэш, а наш шаг распаковывал его второй раз (на Windows x64 — 24 с).
  Свой шаг кэша оставить только на ARM64, где Flutter клонируется без `subosito`.
- [x] **Кэш развёрнутого Flutter SDK на Windows ARM64.** Готового архива Flutter под Windows ARM64
  нет ни у Flutter, ни у сторонних сборщиков, поэтому SDK клонируется заново (58 с), при первом
  запуске качает Dart SDK и собирает утилиту (74 с), а сборка докачивает файлы движка (25 с).
  Кэшировать каталог SDK целиком после использования, с ключом по коммиту ветки `stable`;
  сравнить время с прогоном 269 и убрать кэш, если выигрыша нет. Итог: установка 1:21–2:06 против
  2:57 в прогоне 269 (прогоны 275–277), кэш оставлен.
- Владелец решил не запускать сборки до проверки кода и не объединять сборки iOS; Dev Drive,
  частичный клон Flutter и замерочный workflow ему не интересны.

### Находки прогона на сборке v1.61.0+73 (2026-11-04, отчёт владельца)

- [x] **WalletConnect: ответ на `wallet_switchEthereumChain` не уходит, очередь встаёт.** dApp на
  `@walletconnect/sign-client` 2.17.0 получает `session_update` и `chainChanged`, но не ответ на запрос;
  следующие запросы не обрабатываются до перезапуска. По исходникам: Reown (`reown_core`
  `Pairing.sendRequest`) ждёт ответа собеседника на каждое своё сообщение, `sign-client` подтверждает
  `wc_sessionUpdate`, а на `wc_sessionEvent` при успехе не отвечает. `switchSessionChain` ждал
  `emitSessionEvent` бесконечно, ответ на запрос не отправлялся, а очередь ждала обработчик. Отправлять
  `chainChanged` без ожидания ответа; регрессионный тест адаптера Reown с поддельным `IReownWalletKit`.
- [x] **AirGap: текст после подписи.** «Подпись готова — покажите QR в MetaMask», хотя QR виден только
  после «Продолжить»; шаг 3 обещает, что MetaMask «отправит перевод в сеть», а подпись сообщения в сеть
  не уходит. Сказать, где QR, и не обещать перевод.
- [ ] **Владелец — повторный прогон** переключения сети с тем же dApp: ответ доходит, следующий
  запрос (`personal_sign`) обрабатывается без перезапуска.
- Не берём: «Сканировать запрос» обрезан сверху — тест раскладки на 1080×2340 (2.625) показал зазор
  12 px до описания и подпись целиком внутри кнопки; обрезать её может только край прокрутки. Адрес
  «От кого» — см. «Находки прогонов на v1.61.1»: владелец решил добавить кнопку копирования.

### Находки прогонов на v1.61.1 (2026-11-04, отчёт владельца)

- [ ] **WalletConnect: двойное нажатие «Сменить сеть»/«Одобрить».** Контроллер игнорирует второе
  нажатие, пока первое обрабатывается, но кнопки остаются активными, а нажатие не привязано к
  показанному запросу: второе нажатие после ответа (или второй лист PIN, открытый двойным нажатием)
  одобряет уже следующий запрос очереди, которого пользователь не видел. Привязать одобрение и отказ к
  запросу карточки, не пускать повторное нажатие и выключать кнопки, пока запрос обрабатывается.
- [ ] **Список активов: переполнение строки** при длинной сумме — `Text(amount)` без ограничения ширины
  в `_AssetRow`. Ограничить ширину суммы половиной строки и переносить её, не обрезая цифры.
- [ ] **AirGap: копирование адресов в превью** (от кого, кому, получатель или распорядитель токенов).
  Сейчас их можно только выделить; на Android, Windows и Linux кнопки копирования нет. Владелец решил
  добавить кнопку.
- [ ] **Матрица:** фраза «переключение сети — единственный открытый дефект» устарела — исправлено в
