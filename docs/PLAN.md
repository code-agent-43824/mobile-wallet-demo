### Подпись EIP-712: общее превью (начато 2026-11-03 по решению владельца)

- [x] **`wallet_getCapabilities` без `atomic`.** По EIP-5792 `atomic: unsupported` значит «пакеты
  принимаю и выполняю последовательно», а `wallet_sendCalls` кошелёк не принимает. Без `atomic`
  ответ значит «пакетов нет», и dApp сразу шлёт вызовы по одному через `eth_sendTransaction`.
- [x] **Общее превью EIP-712 для WalletConnect.** Сейчас видно только «тип @ домен». Показать домен
  (приложение, версия, сеть, контракт), тип и все поля сообщения. Если это разрешение тратить
  токены (есть `spender`), — заметное предупреждение: кому, сколько (максимум типа — «без
  ограничения»), до какого срока. `chainId` домена, отличный от сети запроса, блокирует подпись:
  такую подпись можно использовать в другой сети.
- [x] **EIP-712 через AirGap** с тем же превью; сеть домена должна быть Mainnet или Sepolia.
- [~] **Владелец — живой прогон:** `eth_signTypedData_v4` через WalletConnect (Permit на Sepolia) и
  через AirGap из MetaMask. 2026-11-25 (Windows, v1.62.0): AirGap EIP-712 (Ether Mail, 8 кадров из
  файлов) — превью полное, ecrecover даёт кошелёк. Остались Permit через WalletConnect и запрос от MetaMask.

  PIN из 6 цифр решил, что ждут 4. Длина PIN нигде не хранится (и хранить её — подсказка подбору),
  поэтому точки показывают только введённые цифры и одну бледную — место следующей. Тест в
  `widget_test.dart` (lock-on-open).
- [x] **Удаление кошелька телефона.** Функции нет. В настройках — «Опасная зона»: удалить кошелёк с
  предупреждением, что без сохранённой seed-фразы средства пропадут, и отдельным подтверждением.
  Удаляются зашифрованная фраза, ключ биометрии и кэш балансов этого адреса; сессии WalletConnect
  адреса разрываются; дальше — карта, если она есть, иначе экран приветствия. Подтверждение — диалог с
  адресом и флажком, без PIN: забывший PIN тоже должен суметь начать заново. Попутно: QR аккаунта
  AirGap сбрасывается и при смене кошелька — раньше оставался QR прежнего аккаунта. Тест:
  `test/delete_wallet_test.dart`.
- [x] **Клавиши PIN на сгибе Duo (владелец, 2026-11-26).** На раскрытом Duo клавиши экрана блокировки и
  листа PIN стояли на сгибе. Панель PIN измеряет, где внутри неё середина окна, и держит полосу 64 pt

  клавиатура ниже (если помещается). Листы с клавиатурой берут боковой отступ только там, где заходят под
  вырез. Тест: в раскрытых позах ни одна клавиша не ближе 24 pt к сгибу; на прежнем коде падает в трёх случаях.
- [x] **Находки тестировщика на Windows v1.62.0** (`device-test-matrix.md`): QR длиннее 200 символов
  не читается из файла (zbar читает); «Подписать транзакцию» в AirGap недоступна по Tab; однократный
  выход при выборе текстового файла вместо изображения — проверить путь разбора файла.
